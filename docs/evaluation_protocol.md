# Frozen evaluation protocol v1

Hypothesis: MAUD QLoRA training improves Qwen3-8B answers to the predefined deal-point questions on unseen agreements. The supplied passages are already extracted. No claim about general legal expertise, full-contract retrieval, legal advice, or guaranteed improvement.

The split is chosen once by ascending SHA-256 of `maud-agreement-v1-42:<contract_id>`: 106 train, 23 validation, 23 test agreements. Main and abridged rows follow their named agreement. All 3,680 counterfactual rows are excluded because the released file lacks reliable source provenance. Official files remain byte-identical and separate. No performance-based split search. Test labels are read only for integrity, answer-schema and support audits until final evaluation; no test model predictions or error inspection during iteration.

The task unit is the original `(question, subquestion)` pair (144 effective tasks, 92 parent questions). Answers and integer mappings come from the official CSV schema, checked consistently across every row. Multilabel tasks stay as binary subquestions; conditional questions absent from the official rows are not invented. We do not enforce cross-question constraints after prediction. A secondary parent-question score averages subquestion F1 within a parent, then parents equally.

For binary subquestions the CSV `answer` is the full parent answer list, not the binary target. Following the pinned `MultiBinaryDatasetSubQuestionSpec`, label 0 maps to `<OTHER>` and label 1 to the named subquestion option. Verify membership in the raw comma-space-delimited answer list against every integer label; preserve the raw `answer` and add a separate `target_answer`. The prompt explains `<OTHER>` as this particular option not being included. Multiple-choice mappings continue to use their official integer-to-answer strings.

Primary: equal mean of per-task macro-F1 over the frozen eligible task set. Eligibility uses training support only: at least 10 source agreements and at least two classes each represented in 3 training agreements. F1 averages **all officially valid labels**, including labels unsupported in training or evaluation. Zero denominators produce F1=0. A task absent from a scored subset is omitted with coverage reported; the full validation/test evaluation must report missing eligible tasks explicitly. Eligibility is never recomputed from model outputs or bootstrap samples. The same fixed label set and eligibility apply to every model. Per-task and per-category results also expose ineligible tasks. Categories average eligible task F1 equally, while accuracy is example-weighted.

Greedy decoding, batch size 1, maximum 8 new tokens, no sampling, no thinking, one uppercase answer letter A–Z. Whitespace is stripped; any other text (explanation, lowercase, multiple letters, empty answer, unlisted option) is invalid (-1). Invalid outputs count as incorrect accuracy and a false negative for the true class; they are not a new class in the F1 average. Missing, duplicate or foreign prediction IDs and metadata/label mismatches are hard errors. Preserve raw outputs, generated token IDs, label mappings, passage/prompt hashes, token counts, timing, model/config/code/split identity. No LLM judge, generated confidence probabilities, fuzzy answer repair, or best-of-N.

Rare labels have training frequency <=10% within their task, including zero-support valid labels. Report pooled rare-label recall/accuracy, macro recall across present rare task-label pairs, and individual label support/F1. Natural frequency sampling: every retained training row appears exactly once in an epoch after a seeded shuffle; no oversampling. Effective batch size 16, except the final partial batch, whose true size is used for loss averaging.

Normalized exact and exhaustive 5-word-shingle Jaccard >=0.90 overlap (at least 26 unique shingles) are audited within deal-point type and same task across agreements. Unicode NFKC, casefold and whitespace normalization retain numbers. Shared boilerplate is retained; report validation/test results on a precomputed subset without exact/near training overlap as a sensitivity analysis. Lexical similarity is not semantic equivalence, and this audit does not prove absence of every kind of leakage. Whole-contract exact hashes are checked. Pretraining contamination is unknown.

Context is selected from tokenized full prompts, options and passages before model experiments, rounded up to 256 tokens, reserving 8 answer tokens. Overflow is an error; no silent truncation. Length statistics may use test inputs without evaluating answers. Untuned and tuned Qwen use the same pinned tokenizer/model, NF4 double quantization, BF16, chat template with `enable_thinking=False`, prompt, context, generation and scoring. Greedy non-thinking classification is our deterministic engineering choice; Qwen's general generation recommendation uses sampling.

MAUD minority-class AUPR is deferred in v1. The original `pr_curves.py::from_results_binarized` uses `2*logit[class] - sum(logits)` and flips truth/scores when the one-vs-rest positive class exceeds half the sample, then uses average precision. Original aggregation averages answers and questions. Generated letters provide no meaningful continuous option score, and generated confidence is not probability. Do not relabel accuracy/F1 as MAUD AUPR. A future preregistered option-likelihood scorer must be validated against the pinned original scorer before reporting this metric.

Majority baseline uses training counts per task, tie broken by lowest official label ID. Untuned baseline is fully evaluated on validation before substantive training. Epoch validation uses this same primary metric. Keep the earliest checkpoint on ties; stop after two consecutive epochs without strict improvement over the best (patience 2). Train at 3e-5 for up to six epochs. Other candidate learning rates {1e-5, 1e-4} require journaled evidence; the original encoder search is not a Qwen optimum.

Final test access requires a selection record identifying the chosen adapter/checkpoint and frozen configuration before computing any test predictions. Compare frozen untuned Qwen and selected tuned Qwen on all test rows once. Paired agreement bootstrap resamples the same 23 agreements with replacement for both models (2,000 replicates, seed 42), preserving row multiplicity; recompute fixed-label, fixed-task metrics and report percentile 95% intervals and paired differences. Report omitted tasks/degenerate replicates. Resampling does not resolve small sample size, repeated passages, seed variability or pretraining contamination.

Track example-weighted accuracy, invalid rate, rare answers, per-task/per-category/per-agreement errors, overlap novelty, main/abridged strata, length buckets, latency, GPU peak allocated/reserved memory, generated tokens/s and examples/s. Runtime estimates must use actual measured optimizer steps (discard warmup) and full validation throughput. Unfinished/failed runs and engineering smoke tests remain distinguishable from substantive experiments. No paid API comparator is enabled without authorized access and budget.
